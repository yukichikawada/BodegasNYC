# BodegasNYC — Reach Goals Backlog

Companion to [`PRD.md`](./PRD.md). Everything here is explicitly **out of MVP scope**. Each row is written to be self-contained enough to eventually become its own `/plan` session — feed one row at a time to `/plan`, then use the `publish-plan` skill to push the resulting plan to the Notion "Claude Plans" database for a Routine to pick up.

Effort is a rough T-shirt size (S/M/L/XL), not an estimate — recalibrate once MVP architecture exists.

**Sign-off column:** whether this item needs your judgment call *before* a Routine builds it unattended, versus being safe to hand off autonomously once its dependencies are met. This is deliberately not a "model tier" annotation — which model/effort level to use is a runtime decision made at `/plan` time, not something worth freezing into a backlog that will outlive today's model lineup.

| Ephemeral per-bodega chat | Social | Live chat room per bodega; messages TTL-expire and are never persisted to durable storage — sidesteps moderation/retention burden by design. | M | **Yes** — TTL policy and rate-limiting are policy calls, not implementation details. | Needs a realtime transport (Supabase Realtime is the natural fit given the existing backend choice).
